A way to run a large, long project as a household of AI agents. The guide itself is [hawaii-method.md](hawaii-method.md).

## Giving back

If you use the method extensively, we suggest a donation of $25 to the Hawaii H.O.M.E. Project, Waikiki Health, or Kuaʻāina Ulu ʻAuamo (KUA). See the guide, Part B, section 1, "Giving back."

## Other languages

The guide is in English, but a household can work in other languages. See [languages.md](languages.md).

## Versions

Each shared version is a git tag named by date (`2026-11-02`). `CHANGELOG.md` says what changed in each one and why. To get the exact file someone received:

```
git show 2026-11-02:hawaii-method.md > hawaii-method_2026-11-02.md
```

A household records the version it follows in its HOUSEHOLD.md, section 1 (for example, "Hawaii Method 2026-11-02").

## Contributing

Suggestions and fixes are welcome by pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Editing (maintainers)

1. Edit `hawaii-method.md` in this folder (Cowork pointed at this folder, or any editor).
2. Commit with a message that says what changed and why, and add a line to `CHANGELOG.md`.
3. When you send a version to someone, update the version line at the top of the guide, tag the commit with today's date, and push the tag.
